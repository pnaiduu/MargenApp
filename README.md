# Margen

Premium web retainer agency portfolio — single-page site built with Next.js App Router.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

The site adapts to your system light/dark preference automatically.

## Structure

- `app/page.tsx` — entire portfolio (all sections)
- `app/globals.css` — all styles and CSS variables
- `app/layout.tsx` — fonts and metadata
- `public/samples/` — full HTML demo sites shown in preview modals
